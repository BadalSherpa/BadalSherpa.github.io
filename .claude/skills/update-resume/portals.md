# Job portals to refresh with the new resume

Start URL is where the resume upload control lives (or the closest page to it).
Update the "Notes" column whenever a run learns something (button text, gotchas)
so the next run is faster. Add/remove rows to change which portals are updated.

| Portal | Start URL | Notes |
|---|---|---|
| Naukri | https://www.naukri.com/mnjuser/profile | "Update resume" in the Resume card; replaces the existing file. |
| LinkedIn | https://www.linkedin.com/jobs/application-settings/ | Saved resumes for Easy Apply. Upload the new one; set it as default if a toggle/radio exists. Don't delete old ones unless asked. |
| Indeed | https://profile.indeed.com/ | Resume section → replace/upload file. |
| Hirist | https://www.hirist.tech/ | Open the profile page from the avatar menu → resume/CV section. |
| foundit | https://www.foundit.in/seeker/profile | "Update resume" in the profile header/resume card. |
| Instahyre | https://www.instahyre.com/candidate/profile/ | Resume section → upload/replace. |
| Wellfound | https://wellfound.com/profile/edit/overview | Resume field on the profile edit page; save the form after upload. |
